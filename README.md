Steps to run this project on localhost using XAMPP:

1. Open XAMPP and start the Apache and MySQL modules.
2. Type in http://localhost/phpmyadmin in your web browser.
3. Export the database file word_blaster.sql into phpMyAdmin.
4. Extract and transfer the systemproject folder over to xampp/htdocs.
5. Open the file named login.php in your web browser or enter this url into the web browser http://localhost/systemproject/login.php.
6. Project should be running properly.
